体验区

纯静态页面：Key 与聊天数据只保存在你的浏览器里。先选一张角色卡，再填模型设置（在设置页）。

没有卡？长按任意一张卡图 → 保存到相册 → 再用上面的按钮从相册导入它（微信里最顺的导卡路径）。

Key 未配置时发不出消息：先到设置页填一家服务商与 Key。

设置

模型设置

Key 以此设备上的浏览器密钥加密存放（WebCrypto）；安全性弱于 App 端系统级钥匙串，建议只在自己手机上用。豆包、腾讯、MiniMax 不允许网页直连，未列入；找不到你的服务商可选「自定义」。

世界书（关键词自动触发）

一条 ＝「触发关键词」＋「设定内容」。对话里（最近几条消息）说到关键词时，这条内容会自动注入提示词，让角色知道这些设定——和 App 的世界书一个思路，这里是最简版。

AI 生图（/images/generations）

用你配置的服务商画图：需在上面「模型设置」里填一个生图模型（如智谱 cogview-3-flash、硅基流动 Kwai-Kolors/Kolors）。豆包 / 腾讯 / MiniMax 不允许网页直连。会话页的「生图」按钮也走这个模型。

生成角色卡（AI 创作）

一句话描述你想要的角色，用你配置的模型生成一张角色卡，可加入上面的卡列表。

数据与备份

聊天记录、角色卡都只存在这台设备的浏览器里（IndexedDB）。换设备或清理浏览器数据会丢——用备份 JSON 带走或恢复。备份不含 API Key。

本站为纯静态页面，无后端：聊天请求由你的浏览器直连服务商，数据不经过本站服务器。

演示内容为虚构；请遵守所使用服务商的条款与当地法律法规，勿用于违法用途。
