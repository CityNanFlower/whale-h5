模型与 Key

每家服务商的地址、模型与 Key 分开保存；点一行切换过去，聊天就用这一家。

这家服务商的设置

Key 以此设备上的浏览器密钥加密存放（WebCrypto），每家一把；安全性弱于 App 端系统级钥匙串，建议只在自己手机上用。豆包、腾讯、MiniMax 不允许网页直连。

AI 生图测试

用设置里的生图模型画一张，验证这家服务商允许网页直连。

数据与备份

聊天记录、角色卡、世界书都只存在这台设备的浏览器里。备份 JSON 不含 API Key。
